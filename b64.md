# Base64

```bash
# Encode to new file
base64 < in.txt | tr -d '\r\n' | fold -w 76 > out.txt

# Encode in place
base64 < file.txt | tr -d '\r\n' | fold -w 76 > file.txt.tmp && mv file.txt.tmp file.txt

# Decode to new file
tr -d '\r' < in.txt | base64 -d > out.txt

# Decode in place
tr -d '\r' < file.txt | base64 -d > file.txt.tmp && mv file.txt.tmp file.txt
```
